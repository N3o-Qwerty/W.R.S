Write-ups

Walkthroughs of public practice rooms. We write them to show the method — how we enumerate, where the foothold comes from, and how each step leads to the next — not just to hand over the answers.

TryHackMe Rooms

Silver Platter

Linux · Easy. A Silverpeas authentication bypass, an IDOR in private messages, and privilege escalation through a reused password in the auth log.

Anthem

Windows · Easy. Careful enumeration of an Umbraco blog, credentials in robots.txt, then RDP access and a hidden-file privilege escalation.

Blueprint

Windows · Easy. An exposed osCommerce installer on an old XAMPP host gives remote code execution — and, because the stack runs as SYSTEM, instant full control.

Chocolate Factory

Linux · Easy. A web command panel, a key hidden in a photo with steghide, SSH with a recovered key, and a sudo editor to root.

Hack Smarter Labs

Realistic, engagement-style labs from Hack Smarter, published with the creator's permission.

Welcome

Active Directory. One phished account to Domain Admin: a cracked onboarding document, a password spray, an ACL abuse chain, and an ADCS ESC1 certificate attack.

Martini

Active Directory. A guest-readable notes share leaks a password, a reused service account turns out to be privileged, and a secrets dump takes the domain.

Implicit

Web / secure code. An OAuth implicit-grant SSO trusts a username instead of the token, giving account takeover — then you patch the code and re-test.

Casino

Web / Linux. A guest-WiFi portal leaks its guest database, an SSTI in a profile field gives a shell, and a careless bash history hands over root.

Dark

Linux. An outdated WordPress site, a malicious plugin uploaded for code execution, and privilege escalation through a credential left in a readable log.

Pollution

Web · Easy. A client-side prototype pollution gadget in a Node.js SOC app, delivered to an admin via a mail feature to read a protected page.

Exception

Linux. A Rocket.Chat server on a port the fast scan missed, a NoSQL-injection RCE, a reused database password for SSH, and a sudo editor to root.

Edge

Windows. An assumed-breach WinRM foothold, credentials scraped from Microsoft Edge's process memory, and a pivot through a portal and a PuTTY password to administrator.

Shadowgate · Technique

Active Directory · technique note. Targeted Kerberoasting: abusing write access over a user to set an SPN, roast it, and crack the ticket offline. One technique from the lab, not a full walkthrough.

How We Write These

  • Labs only, with permission. We write up public practice rooms and Hack Smarter labs (shared with the creator's permission) — never a client engagement or paid course content.
  • Flags redacted. We show the commands and the reasoning but hold back the literal flag and password values, so the room is still worth doing yourself.
  • Method over answers. The goal is a repeatable process you can apply to a machine you have never seen.
