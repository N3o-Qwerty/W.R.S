Martini

Hack Smarter · Active Directory · Black box. A guest-readable notes share leaks a password; a service account turns out to be privileged; and a secrets dump hands over the whole domain.

A Hack Smarter lab, shared with permission. Credentials, hashes, and flag values are redacted — the point is the attack chain, not the answers.

1. Anonymous SMB

The DC blocks ping, so scan with -Pn. It is a Server 2025 domain controller. SMB signing is off and a null session is allowed, so NetExec reads the shares without credentials and finds a non-default notes share.

nxc smb TARGET                 # grabs the domain name
nxc smb TARGET -u '' -p ''  --shares
smbclient.py guest:''@DC       # browse the notes share

The notes share is world-readable and contains a plain text file.

2. Credentials in a Note

The note is a to-do list with a password jotted at the bottom for a regular user. A null-session RID brute also enumerates the domain's accounts, so we know which names are real.

nxc smb TARGET -u guest -p '' --rid-brute

That first user's password also works for a service account — password reuse between a person and a service, and the service account turns out to be the one that matters.

3. Secrets Dump to Domain Admin

The service account has the replication rights needed to pull the domain's secrets (a DCSync). Impacket's secretsdump extracts every account hash, including the krbtgt key and the built-in administrator.

secretsdump.py 'DOMAIN/svc_account:PASS@DC'

With the administrator's NT hash in hand, pass-the-hash for a shell on the DC. Game over — and with the krbtgt hash, the domain can be forged at will (a golden ticket), which is the impact to flag in the report.

evil-winrm -i DC -u Administrator -H NTHASH

What To Take Away

  • Null sessions and anonymous shares hand an attacker the domain for free. Disable them.
  • Passwords in notes files are common and devastating. Don't store secrets in readable shares.
  • Reuse between a user and a service account is what turned a low-privilege note into Domain Admin.
  • Any account with replication rights is effectively Domain Admin via DCSync. Audit who holds them.
