Start Here

A learning path into offensive security, from the basics to a first practical certification. Go in order, and move on only when you meet each stage's goal.

The Path

  1. Foundations

    Learn how computers talk to each other before trying to break them: networking basics (IP addresses, ports, DNS, HTTP), the Linux command line, and how the web works.

    Use: TryHackMe Pre Security path and its SEC0 certification. OverTheWire Bandit for Linux practice.

    Ready to move on when: You can explain what happens when you type a web address and press Enter, and you are comfortable moving around a Linux terminal.

  2. Core security skills

    Cover the main areas once, hands-on: scanning and enumeration, web basics, cryptography basics, Windows and Active Directory fundamentals, and common tools.

    Use: TryHackMe Cyber Security 101 path and its SEC1 certification.

    Ready to move on when: You can scan a practice machine, read the results, and say what each open service is for.

  3. Theory and vocabulary

    Learn the language employers and clients use: risk, controls, incident response, identity, cryptography, and governance.

    Use: CompTIA Security+ (SY0-701). Use the official exam objectives as your checklist.

    Ready to move on when: You can read a security policy or a job description and understand every term in it.

  4. Hands-on practice

    This is where most of the skill is built. Work through practice machines and web labs, and take notes on every one. Read a walkthrough only after you have been stuck for a while, then redo the machine without it.

    Use: Hack The Box and TryHackMe machines, PortSwigger Web Security Academy, and a small home lab.

    Ready to move on when: You can finish easy and some medium machines without a walkthrough, and your notes are good enough to reuse.

  5. First offensive certification

    A practical exam proves you can do the work under time pressure and write it up. Report writing is part of the exam, so practise it.

    Use: OffSec PEN-200 course and the OSCP exam: a hands-on exam of just under 24 hours, followed by a written report.

    Ready to move on when: You can compromise unfamiliar machines methodically and document each step so someone else can reproduce it.

  6. Specialize and give back

    Pick an area and go deeper: web applications, Active Directory, cloud, hardware, or AI systems. Teaching is one of the best ways to learn, so publish write-ups of retired machines or build a practice room.

    Use: OWASP testing guides, the OWASP Top 10 for LLM Applications, and writing for the community.

    Ready to move on when: Other people learn from something you made.

Habits That Help

  • Take notes from day one. Write down every command that worked and why. Your notes become your own cheat sheet.
  • Enumerate before you exploit. Most stuck moments come from something you did not look at closely, not from a missing exploit.
  • Set a timer when stuck. Give a problem a fixed time, then read a hint. Afterwards, write down what you missed and why.
  • Repeat machines. Redoing a machine a week later without notes shows what you actually learned.
  • Practise reporting. Write a short report for machines you finish. Clear writing is half of professional testing.
  • Stay legal. Only test systems you own or have written permission to test.
