Bender Room

A practice room we built and published on TryHackMe. It combines an attack on an AI application with classic Linux privilege escalation.

What You Practise

  • Prompt injection. How instructions hidden in user input can change what an AI application does.
  • What the model can reach. Why the data and tools connected to an AI application matter more than the model itself.
  • Linux privilege escalation. Moving from a low-privilege foothold to full control of the machine.

Spoiler-Free Hints

  • Enumerate the web app first. Check the usual places a site tells you more than it means to — robots.txt is a good start — and note any usernames you find.
  • Make the assistant misbehave. Find the phrase or input that pushes it out of its normal script. When it breaks, read its output carefully.
  • That output is encoded, not random. What looks like gibberish is a secret in disguise. Work out the encoding and decode it.
  • Enumerate after the foothold. Once you have a shell, run the normal Linux checks in order. A file that runs with more privilege than it should is the way up.
