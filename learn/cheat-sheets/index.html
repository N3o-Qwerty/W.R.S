Cheat Sheets

Quick references for lab work and capture-the-flag practice.

Only test systems you own or have written permission to test. Practice on labs built for it.

Nmap Quick Reference

Replace TARGET with the address of your lab machine.

Default scripts and version detection, saved in all formats

nmap -sC -sV -oA scans/initial TARGET

All 65,535 TCP ports

nmap -p- --min-rate 1000 -oA scans/all-ports TARGET

Detailed scan of specific ports

nmap -p 22,80,445 -sC -sV TARGET

Top UDP ports (slow; needs root)

sudo nmap -sU --top-ports 20 TARGET

Skip host discovery when ping is blocked

nmap -Pn TARGET

Find live hosts on a lab network

nmap -sn 10.10.10.0/24

NetExec Quick Reference

NetExec (nxc) tests Windows and Active Directory services. USER and PASS are credentials you are authorized to use.

Find Windows hosts and see names, domains, and SMB signing

nxc smb 10.10.10.0/24

Check credentials and list shares

nxc smb TARGET -u USER -p PASS --shares

List domain users

nxc smb TARGET -u USER -p PASS --users

Show the password policy before any guessing

nxc smb TARGET -u USER -p PASS --pass-pol

Test one password across a user list

nxc smb TARGET -u users.txt -p PASS --continue-on-success

Run a command over WinRM

nxc winrm TARGET -u USER -p PASS -x whoami

Semgrep Quick Reference

Semgrep finds bug patterns in source code. Run it on code you own or are authorized to review.

Scan a project with the community rules

semgrep scan --config auto .

Run a specific ruleset from the registry

semgrep scan --config p/owasp-top-ten .
semgrep scan --config p/secrets .

Run only your own rule file

semgrep scan --config ./myrules.yaml src/

A minimal rule: flag a dangerous call

rules:
  - id: python-eval-use
    languages: [python]
    severity: WARNING
    message: Avoid eval() on untrusted input.
    pattern: eval(...)

Match a call but ignore a safe case

rules:
  - id: subprocess-shell-true
    languages: [python]
    severity: ERROR
    message: shell=True with untrusted input is command injection.
    patterns:
      - pattern: subprocess.$F(..., shell=True)
      - pattern-not: subprocess.$F("...", shell=True)

Fail CI on findings, output SARIF

semgrep scan --config auto --error --sarif -o results.sarif .

Practice Machine Checklist

A first pass for any lab machine. Most of the work is enumeration.

  1. Scan

    Run a full TCP port scan, then a detailed scan of the open ports.

  2. Enumerate each service

    For every open port, find the software and version and look at what it exposes without logging in.

  3. Web

    Browse the site by hand first. Then look for hidden directories, login pages, file uploads, and parameters.

  4. Credentials

    Note every username, password, and key you find, and try them on every service.

  5. Foothold

    Pick the most likely weakness, test it, and keep notes on what you tried.

  6. Privilege escalation

    Check who you are, what you can run, scheduled tasks, unusual files, and stored credentials.

  7. Write it up

    Record each step with the command and its output while it is fresh.
